# Проверка и очистка датасетов Казани

Исходно 1454 записей. В подборке 434 записей (408 разных OSM ID), исключено 1020. Фотографии привязаны к 179 разным точкам; у 229 imageUrl=null.

## Правила очистки

1. Карточки GitHub сопоставлены по OSM ID, включая сведения об одном месте в разных категориях.
2. Сохранены точки с внешними сведениями либо конкретными фактами в OSM: описанием, автором, датой или содержательной надписью. Одна лишь пара «название + тип» не считалась достаточной для культурного рассказа.
3. Безымянным объектам восстановлены названия только при наличии связанной статьи/Викиданных или подтверждения в источнике. OSM-теги не переписывались.
4. Сопоставлены связанные статьи Wikipedia/Wikidata, официальные карточки из репозитория, 38 страниц каталога парков и доступные сайты учреждений из OSM. Для 455 исключённых названий выполнен дополнительный поиск; результат ниже показывает его ограничения.
5. Недоступный сайт и пустой поиск не доказывают, что объекта нет. Исключения доступны для ручного восстановления. Не подтверждённый филиал не заменялся другим филиалом сети.
6. Данные о реставрации, закрытии или ограниченном доступе отражены в visitStatus/routeEligible. Значение routeEligible=true означает отсутствие обнаруженного запрета, а не гарантию открытого доступа.

## Что проверено и что остаётся

Дополнительный поиск: {"ok": 83, "<urlopen error timed out>": 9, "HTTP Error 429: Too Many Requests": 363}. Массовое ограничение HTTP 429 не обходилось. Поэтому внешняя проверка не исчерпывающая; журнал исключений обязателен для дальнейшей редакционной проверки.
Фотографии найдены через P18 Викиданных, заглавные изображения связанных статей и изображения конкретных страниц учреждений. Проверены HTTP 200 и тип image/*. Это проверка привязки по источнику и доступности URL, не полная визуальная экспертиза каждого снимка. Для точек с координатами P625 отклонялись изображения при расхождении более 500 метров; этого порога недостаточно для различения соседних корпусов.
imageLicense и imageAuthor заполнены из метаданных Wikimedia там, где они доступны. Лицензия текста OSM не распространяется на фотографии. Если права не установлены, reuseStatus сообщает об этом; такой снимок нельзя считать автоматически разрешённым для публикации.
Категория tatar_food содержит отдельные филиалы. Общий логотип или фотография одного ресторана сети не распространялись на остальные адреса.
Маршруты по данным не запускались. В переданном API-reference нет адреса тестового окружения. Postman-кейсы подготовлены, но HTTP-результаты не получены.
Геометрические центры way/relation не обязательно являются входами. Пересечения между категориями сохранены. Для исключения одной достопримечательности под разными ID нужен отдельный канонический справочник — одинаковые названия разных филиалов не объединены.
